# Lab 2: Agile Backlog Creation & Sprint Simulation

## Project
Student Project Portfolio & Showcase App

## Epics
1. Project Submission & Management
2. Project Evaluation & Voting
3. Leaderboard & Results

## User Stories

### Epic 1: Project Submission & Management
- As a student, I want to submit project details so that my project can be showcased.
- As a student, I want to upload multimedia artifacts so that others can view my work.
- As a student, I want to edit my submission so that I can correct mistakes.

### Epic 2: Project Evaluation & Voting
- As a judge, I want to grade projects using a digital rubric so that evaluation is consistent.
- As a public user, I want to vote for projects so that I can support my favourites.
- As a system, I want to prevent duplicate or fraudulent votes so that voting remains fair.

### Epic 3: Leaderboard & Results
- As a user, I want to view project rankings so that I can see leading projects.
- As a judge, I want to view evaluation results so that I can review project performance.
- As a student, I want to view my project's results so that I can understand its performance.

## Story Points
- Submit project details: 3
- Upload multimedia artifacts: 5
- Edit project submission: 3
- Grade projects using a digital rubric: 5
- Vote for projects: 3
- Prevent duplicate or fraudulent votes: 8
- View project rankings: 3
- View evaluation results: 3
- View own project results: 2

## Sprint Plan
Sprint 1: Project submission and editing.
Sprint 2: Project evaluation, voting, and results.

## Reflection
Agile backlog creation breaks the project into manageable user stories. Prioritization and story-point estimation help the team plan its work. Sprint boards and burndown charts help track progress and identify unfinished tasks.
